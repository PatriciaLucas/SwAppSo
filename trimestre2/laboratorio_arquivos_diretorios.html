Laboratório 1: Arquivos, Sistemas de Arquivos e Diretórios

Atividade prática de continuação da aula teórica — Softwares, Aplicativos e Sistemas Operacionais

Antes de começar

Nesta aula prática você vai colocar a mão na massa nos conceitos vistos na aula anterior: arquivos, atributos, sistemas de arquivos, volumes, diretórios e caminhos de acesso. O laboratório está dividido em duas trilhas independentes:

  • Trilha Windows — para fazer com Windows;
  • Trilha Linux — para fazer com Debian.
Atenção Todo o trabalho deve ser feito dentro de uma pasta própria, criada por você, para não bagunçar os arquivos de outros alunos que usam o mesmo computador. Nunca apague ou modifique arquivos fora dessa pasta.
Como entregar Ao final da trilha, responda o Relatório final no caderno.

Conceitos-chave da prática

Interface gráfica (GUI) x linha de comando

Até agora você provavelmente só usou o computador clicando em ícones, janelas e botões. Essa forma de interação é chamada de GUI (Graphical User Interface, ou Interface Gráfica do Usuário) — é o caso do Explorador de Arquivos no Windows e do aplicativo "Arquivos" no Debian.

Existe também outra forma de interagir com o sistema operacional: digitando comandos de texto em vez de clicar. Essa forma é chamada de linha de comando (ou CLI, Command Line Interface). Nela, você escreve uma instrução e o computador executa exatamente o que foi pedido.

Conceito
  • No Windows, o programa que abre uma linha de comando chama-se Prompt de Comando (também existe o PowerShell, mais moderno).
  • No Linux (Debian), o programa equivalente chama-se Terminal.
Ou seja, "Prompt de Comando" e "Terminal" cumprem o mesmo papel em cada sistema: são a porta de entrada para a linha de comando. Nenhum dos dois é uma GUI — ambos são interfaces de texto. É o Explorador de Arquivos (Windows) e o aplicativo Arquivos/Nautilus (Debian) que são as GUIs equivalentes entre os dois sistemas.

O que é um caminho (path)?

Como os arquivos ficam organizados dentro de uma árvore de diretórios (pastas dentro de pastas), não basta saber o nome de um arquivo para localizá-lo — é preciso saber também onde ele está. Essa localização completa, escrita como texto, é chamada de caminho de acesso (path).

Definição Um caminho pode ser de dois tipos:
  • Caminho absoluto — começa sempre a partir da raiz do sistema de arquivos e descreve a localização completa do arquivo, não importa de onde você esteja. Ex.: C:\Users\Maria\lab\ci067.txt (Windows) ou /home/maria/lab/ci067.txt (Linux).
  • Caminho relativo — parte do diretório de trabalho atual (a pasta em que você está no momento). Usa os elementos especiais . (o próprio diretório atual) e .. (o diretório pai, ou seja, "subir um nível"). Ex.: se você está em lab, o caminho relativo para acessar um arquivo dentro da pasta vizinha seria ../avaliacoes/prova.txt.
Exemplo Imagine que você está na pasta documentos e quer acessar um arquivo que está na pasta avaliacoes, que é vizinha (as duas ficam dentro de lab). O caminho relativo seria ..\avaliacoes\arquivo.txt no Windows, ou ../avaliacoes/arquivo.txt no Linux: primeiro .. sobe um nível (de documentos para lab), depois desce para dentro de avaliacoes.

Você vai testar esse conceito na prática, tanto na trilha Windows quanto na trilha Linux, usando comandos que mostram e mudam o diretório de trabalho atual.

Trilha Windows Windows

Você vai usar duas interfaces: o Explorador de Arquivos (GUI) e o Prompt de Comando (linha de comando), além do Bloco de Notas.

1. Explorando pastas e atributos

1

Abra o Explorador de Arquivos (ícone de pasta amarela na barra de tarefas, ou tecla Windows + E). Essa é a interface gráfica (GUI) do Windows para lidar com arquivos e pastas.

2

Navegue até Área de Trabalho (Desktop) e crie uma nova pasta com o seu nome. Clique com o botão direito em um espaço vazio → Novo → Pasta. Renomeie para algo como lab_SeuNome.

3

Entre nessa pasta. Crie um arquivo de texto: botão direito → Novo → Documento de Texto. Renomeie para ci067 e escreva uma frase qualquer dentro dele.

4

Clique com o botão direito sobre o arquivo ci067 e escolha Propriedades. Observe os atributos exibidos: tamanho, data de criação, data de modificação e localização.

Checkpoint 1 Anote no seu relatório: qual o tipo, o tamanho, a data de criação e o caminho completo (localização) do arquivo ci067?

2. Extensões e magic numbers

5

No Explorador de Arquivos, clique na aba Exibir (ou Ver) → marque a opção Extensões de nomes de arquivos. Agora os nomes dos arquivos passam a mostrar a extensão (por exemplo, ci067.txt em vez de apenas ci067).

6

Renomeie o arquivo ci067.txt trocando a extensão para .pdf (o Windows vai avisar que isso pode tornar o arquivo inutilizável — confirme mesmo assim). Tente abrir o arquivo com um duplo clique.

Checkpoint 2 O arquivo abriu normalmente como PDF? O que isso mostra sobre a diferença entre a extensão do nome (o que está escrito) e o conteúdo real do arquivo (os bytes internos, o "magic number")? Volte a extensão para .txt antes de continuar.

3. Caminhos absolutos e relativos

Antes de continuar, revise a explicação sobre caminhos absolutos e relativos na seção de conceitos. Agora você vai enxergar esses caminhos usando o Prompt de Comando, a linha de comando do Windows.

7

Dentro da sua pasta lab_SeuNome, crie duas subpastas: documentos e avaliacoes. Mova o arquivo ci067.txt para dentro de documentos.

8

Clique na barra de endereço do Explorador (a área onde aparece o caminho, no topo da janela) enquanto estiver dentro da pasta documentos. Copie o caminho completo mostrado — esse é um caminho absoluto.

9

Abra o Prompt de Comando (pesquise "cmd" no menu Iniciar). Antes de digitar, veja o que cada comando faz:

O que cada comando faz
  • cd <pasta> — "change directory": muda o diretório de trabalho atual para a pasta indicada.
  • dir — lista os arquivos e pastas que estão dentro do diretório atual.
  • cd .. — sobe um nível, indo para o diretório pai (a pasta que contém a atual).

Agora digite cd Desktop\lab_SeuNome (ajustando o nome da sua pasta) e depois dir para listar o conteúdo. Em seguida digite cd documentos e depois cd .. — observe para onde você volta.

Checkpoint 3 Escreva o caminho absoluto do arquivo ci067.txt (algo como C:\Users\...\Desktop\lab_SeuNome\documentos\ci067.txt). Depois, explique com suas palavras o que o comando cd .. faz e por que isso é um exemplo de caminho relativo.

4. Volumes e letras de unidade

10

No Explorador de Arquivos, clique em Este Computador (ou "Meu Computador"). Observe as letras de unidade disponíveis (C:\, e outras, se houver).

11

Se houver um pendrive disponível no laboratório, conecte-o e observe qual letra de unidade ele recebe. Copie o arquivo ci067.txt para o pendrive.

Checkpoint 4 Quantas letras de unidade apareceram no seu computador? Qual letra o pendrive recebeu?

Trilha Linux (Debian) Debian

Para acessar o Debian, reinicie a máquina e clique em qualquer tecla até aparecer a lista de sistemas operacionais disponíveis. Selecione o Debian com as setas do teclado e clique ENTER.

Você vai usar o Terminal do Debian — a linha de comando do sistema. Para abri-lo, use o atalho Ctrl + Alt + T, ou clique em Atividades (canto superior esquerdo) e digite "Terminal".

Observação O Debian também tem uma GUI equivalente ao Explorador de Arquivos do Windows: o aplicativo Arquivos, que você pode abrir pelo menu Atividades. Sinta-se livre para conferir visualmente, pelo aplicativo Arquivos, as pastas e arquivos que forem criados pelo Terminal ao longo desta trilha.

1. Navegando pelo terminal

1

Abra o Terminal. Antes de digitar, veja o que cada comando faz:

O que cada comando faz
  • pwd — "print working directory": mostra o caminho absoluto do diretório em que você está agora.
  • mkdir <nome> — "make directory": cria uma nova pasta com o nome indicado.
  • cd <pasta> — "change directory": muda o diretório de trabalho atual para a pasta indicada.

Digite pwd e pressione Enter para ver seu diretório de trabalho atual (algo como /home/seuusuario).

2

Crie sua pasta de trabalho dentro do seu diretório pessoal:

cd ~
mkdir lab_seunome
cd lab_seunome

O símbolo ~ é um atalho do Debian que sempre representa o seu diretório pessoal (/home/seuusuario).

3

O comando echo escreve um texto na tela; usando > depois dele, esse texto é enviado para dentro de um arquivo (criando-o, se ainda não existir). Crie um arquivo de texto e escreva algo dentro dele:

echo "Meu primeiro arquivo de laboratorio" > ci067.txt
4

O comando ls lista o conteúdo de uma pasta; com a opção -l ("long"), ele mostra detalhes de cada arquivo. Liste o conteúdo da sua pasta com detalhes:

ls -l
Checkpoint 1 Na saída de ls -l, identifique: o tamanho do arquivo (em bytes), a data de modificação e as permissões (a sequência de letras como rw-r--r--). Copie essa linha para o seu relatório.

2. Atributos com ls -l e file

5

O comando file analisa os bytes iniciais de um arquivo (o "magic number") e informa qual é o tipo real do conteúdo, independente do nome. Use-o no seu arquivo:

file ci067.txt
6

O comando mv ("move") também é usado para renomear arquivos no Linux (mover para o mesmo lugar, com nome novo). Troque a "extensão" do arquivo (no Linux, a extensão é só parte do nome, sem efeito especial no sistema) e rode o file de novo:

mv ci067.txt ci067.pdf
file ci067.pdf
Checkpoint 2 Mesmo com a extensão .pdf, o comando file reconheceu o conteúdo real como quê? O que isso mostra sobre o Linux não depender da extensão para identificar o tipo do arquivo? Renomeie de volta para ci067.txt usando mv.

3. Caminhos absolutos e relativos

Reveja a explicação sobre caminhos absolutos e relativos antes de continuar. Você vai testar os dois tipos usando cd e pwd.

7

Crie duas subpastas e mova o arquivo:

mkdir documentos avaliacoes
mv ci067.txt documentos/
8

Entre na pasta documentos e veja o caminho absoluto:

cd documentos
pwd
9

Agora teste caminhos relativos, usando . (diretório atual) e .. (diretório pai — "sobe um nível"):

cd ..
cd ./avaliacoes
cd ../documentos
Checkpoint 3 Escreva o caminho absoluto completo do arquivo ci067.txt (algo como /home/seuusuario/lab_seunome/documentos/ci067.txt). Explique o que . e .. significam, com base no que você testou.

4. Volumes e pontos de montagem

10

O comando df ("disk free") mostra os volumes montados e o espaço disponível em cada um; a opção -h ("human-readable") exibe os tamanhos em KB/MB/GB, mais fáceis de ler. Execute:

df -h

Perceba que o diretório apresentado não é apresentado de uma forma amigável. Vamos verificar via GUI, abrindo o aplicativo Arquivos e observando as pastas.

11

Se houver um pendrive disponível no laboratório, conecte-o. No Debian, ele costuma ser montado automaticamente dentro de /media/seuusuario/.

Checkpoint 4 Qual foi o ponto de montagem (caminho dentro de /media/...) em que o pendrive apareceu? Compare com a forma como o Windows lida com pendrives (letra de unidade) — qual é a diferença conceitual entre as duas abordagens?

Relatório final (todos os alunos)

Depois de concluir a sua trilha, responda às perguntas abaixo. Se possível, converse com um colega que fez a outra trilha (Windows ↔ Linux) para comparar as respostas.

  1. Cite três atributos de arquivo que você observou na prática (em Propriedades no Windows ou em ls -l no Debian).
  2. O que aconteceu quando você trocou a extensão do arquivo de texto para .pdf? O sistema operacional passou a tratar o conteúdo como um PDF de verdade? Justifique.
  3. Escreva o caminho absoluto de um dos arquivos que você criou, e um caminho relativo equivalente partindo de uma pasta vizinha.
  4. Como o sistema que você usou (Windows ou Debian) identifica um volume de armazenamento (pendrive, disco)? Compare com a explicação da aula teórica.
  5. Qual a diferença entre uma interface gráfica (GUI) e uma linha de comando (CLI)? Cite o nome do programa de linha de comando do sistema que você usou.
  6. Na sua opinião, qual conceito ficou mais claro depois da prática em comparação com a aula teórica? Por quê?
